## 🔭 Selected Work

- **Sensi-Train / SensiLLM / SensiBERT**: a balanced 25,480-instance benchmark spanning 13 cultures for sensitive content detection. Fine-tuned Mistral-7B (QLoRA) reaches 1.00 F1 on the held-out set, and a context-aware BERT reaches 0.96 F1
- **Health Misinformation Detection using RAG**: benchmarked BERT, RoBERTa and Qwen 2.5 with RAG on 12.9K social media posts
- **Factual and Citation Reliability of Web-enabled LLMs**: cross-domain benchmark comparing GPT-5 and Gemini 2.5 Pro on accuracy and source validity
- **NEET Risk Prediction (DSSG)**: LightGBM classifier packaged with Docker and a Streamlit interface for non-technical stakeholders
